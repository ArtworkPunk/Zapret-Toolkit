Почему Zapret Toolkit?

Мы не VPN. Мы не продаем ваши данные. Вся магия происходит локально на вашем ПК.

Local Only

Программа работает как драйвер. Ваши пароли и файлы остаются при вас.

Zero Ping

Пакеты идут напрямую к серверам игр. Идеально для CS2, Valorant и Fortnite.

Smart Stealth

Интеллектуальная подмена отпечатков. Трафик выглядит как обычный серфинг.

Neural Core Architecture

АЛГОРИТМ СВОБОДЫ

Комплексная трансформация сетевого потока. Мы превращаем заблокированный запрос в легальный пакет данных за 0.003 секунды.

Каждый пользователь может создать свой отпечаток в интернете, сделав запросы невозможными для чтения ТСПУ!

01

Перехват

Драйвер WinDivert внедряется в сетевой стек на уровне ядра (Kernel Mode). Он "замораживает" исходящие пакеты до того, как они попадут в фильтр провайдера.

02

Фрагментация

Ядро winws.exe разбивает пакеты на микро-сегменты и модифицирует TCP-заголовки. Используется DUMP-маскировка под легальные сервисы. DPI видит "белый шум".

03

Синхронизация

Сервер назначения собирает фрагменты обратно. Устанавливается прямое шифрованное соединение. Провайдер регистрирует обычную активность без блокировок.

Быстрый старт

1

Скачайте архив

Нажмите кнопку скачать. Распакуйте в удобное место.

git clone https://github.com/ArtworkPunk/zapret-toolkit.git
2

Запустите Меню

Найдите service.bat. Запустите от имени Администратора.

*В меню выберите пункт 7 (DNS) для очистки кэша перед стартом.

3

Активируйте

Выберите пункт 1 (Install Service). Используйте пресет MaxFuckYouDolbaeb.bat.

Система активна.
